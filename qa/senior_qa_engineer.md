# Senior QA Engineer

## Scope

A Senior QA Engineer designs, builds and maintains test automation frameworks integrated into CI/CD pipelines

## Collaboration and Communication

- Creates a culture of quality throughout the development lifecycle
- Mentors others on testing
- Communicates effectively with immediate and dependent teams and stakeholders

## Planning

- Builds testability into features from the start
- Uses AI tools to accelerate test authoring, maintenance, and analysis
- Owns documentation for test automation systems

## Test Strategy

- Designs, builds, and maintains test automation frameworks to increase test coverage
- Integrates automated test suites into CI/CD pipelines
- Performs targeted exploratory and regression testing on new features where human judgment adds the most value

## Experience

- Built or significantly extended a test automation framework
- Integrated automated tests into CI/CD pipelines
- Applied AI tools to quality engineering
